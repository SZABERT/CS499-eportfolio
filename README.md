### Professional Goals and Values
My journey through the Computer Science program has been transformative, providing the technical foundation necessary to transition from logistics and distribution operations into my current role as a Product Analyst in Enterprise Engineering. Serving previously as an infantry officer in the U.S. Army instilled a core foundation of leadership, discipline, and adaptability. However, this academic program gave me the rigorous technical vocabulary and architectural understanding required to succeed in the software industry. My professional goal is to bridge the gap between technical architecture and product strategy. I value clean code, scalable systems, and continuous innovation. Developing this ePortfolio has allowed me to reflect on my growth and tangibly showcase my ability to design computing solutions that deliver measurable business value.

### Collaboration and Stakeholder Communication
A significant portion of my professional identity revolves around facilitating collaboration. In my current role, I lead an enterprise AI adoption pilot, coordinating with diverse development teams to promote an AI first coding mindset. This requires constant, clear communication with various stakeholders. I must translate complex technical constraints into clear cost benefit analyses for business leaders, while also breaking down high level business requirements into actionable items for software engineers. The coursework reinforced these skills by teaching me how to produce professional quality technical documentation, conduct thorough code reviews, and communicate architectural trade offs effectively.

### Software Engineering and Database Design
Throughout this program, I have learned that writing code that simply works is not enough. Software must be maintainable, scalable, and built using industry standard design patterns. Transitioning from writing flat, procedural scripts to developing modular applications using Object Oriented principles like the Model View Controller architecture has been a major milestone in my development. Furthermore, I have developed a strong proficiency in data management. Whether I am integrating a NoSQL solution like MongoDB or designing complex document schemas, I understand how to decouple data from logic to create persistent, reliable applications that scale seamlessly.

### Algorithms and Data Structures
Understanding how to select the right tool for a specific problem is a critical skill for any computer science professional. My coursework has trained me to look beyond surface level functionality and evaluate the algorithmic efficiency of my solutions. By studying Big O notation, sorting algorithms, and advanced data structures, I am equipped to optimize applications for speed and memory usage. For example, converting flat lists and dictionaries into formal Graph structures to implement pathfinding algorithms like Breadth First Search demonstrates my ability to apply theoretical computer science principles to solve practical logic problems.

### Security Mindset
Modern software development requires a proactive approach to security. The program has taught me to anticipate adversarial exploits and build defenses directly into the architecture of an application. Rather than treating security as an afterthought, I practice defense in depth. This includes implementing rigorous input validation to sanitize data and prevent injection attacks, utilizing secure connection protocols for database management, and handling system errors gracefully so that applications do not expose vulnerable infrastructure details when a failure occurs.

## ePortfolio Artifacts Summary
To demonstrate the full range of my computer science abilities, the artifacts following this assessment showcase the continuous improvement of a single application. I selected a Python based text adventure game titled Dracula, which I originally wrote early in my academic career as a simple procedural script. Throughout this portfolio, you will see this artifact transformed across three key categories:

* **Software Design and Engineering:** I completely refactored the codebase to utilize a modular Model View Controller architecture, demonstrating my ability to write clean, decoupled, and maintainable Object Oriented code.
* **Algorithms and Data Structures:** I replaced the rigid map logic with a Graph data structure and implemented a Breadth First Search algorithm to power a dynamic pathfinding feature.
* **Databases:** I replaced the local memory state management with a secure MongoDB backend, utilizing regular expressions to sanitize user inputs and safely store player progress.
